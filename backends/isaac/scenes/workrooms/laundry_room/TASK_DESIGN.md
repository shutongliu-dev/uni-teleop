# 洗衣整理间任务设计与实现边界

2026-10-23 的当前范围为五项双臂任务：原有毛巾摊平、对折和叠放，加上单件展开T恤折叠与单条展开长裤折叠。一个 Agent 在普通 `/episodes` 中控制两台原始 FR3 与官方左、右 SHARPA，共 58 DOF；机器人资产与共享控制能力参照机械 Task10。固定洗衣房仍是 v3，背景衣物和家电继续作为静态陈设。

## 五项任务与形态目标

| 编号 / canonical ID | 初态与目标 | 主要检查 |
|---|---|---|
| Task1 / `towel_flattening` | 将起皱、偏置的单片毛巾摊平摆正 | 整片对应位置、朝向、面积、残余高度、台面支撑和释放 |
| Task2 / `towel_folding` | 将毛巾沿长边中线对折 | 两半材料对应、折后尺寸、层次、位置和释放 |
| Task3 / `towel_stacking` | 将已折毛巾搬到另一条动态已折毛巾上 | 两条都保持折形，下条受台面承托，上条受真实布面支撑 |
| Task4 / `shirt_folding` | 将单件展开T恤收袖并对折衣身 | 材料折形、天然前后衣片厚度、台面支撑和释放 |
| Task5 / `trousers_folding` | 将单条展开长裤对齐裤腿并对折裤身 | 两种等价裤腿折法、材料层次、台面支撑和释放 |

旧 `shirt_stacking` / `trousers_stacking` 作为历史canonical任务保留，当前编号4/5不再指向它们。晾杆搭挂、篮筐分类、家电装卸等仍是后续独立任务；现有洗衣机和烘干机没有因此变成可操作家电。

## 柔性模型与外观边界

毛巾沿用 60 × 40 cm 矩形静止网格、名义厚度 3 mm、质量 108 g。新衣物见 [garment_folding_assets.py](garment_folding_assets.py)：当前T恤选用项目自建的平展前后双面缝合pattern（CC0-1.0，四个真实开口），长裤采用前后两衣片缝合的三开口shell。官方Newton四开口T恤保留原始来源、许可、哈希和试验记录，作为独立候选；当前选择不把它的穿着态投影当展开初态。两件当前材料厚度为1.2 mm，质量分别为180/260 g；参数绑定具体冻结资产。旧 [garments.py](garments.py) 的单材料中面只用于历史叠放版本。

每个新任务只有一件动态衣物，没有 `towel_base`。无应力静止材料网格与展开初态分开保存；优先从完整、无控制的真实PhysX沉降记录生成展开初态，保留原拓扑、静止材料、原生形变及来源哈希，不以折叠目标作初态或逐点运动驱动。初始操作信用为零。衣物参考、材料对应及底面采样随资产冻结，真实展开参考不足时的临时投影不能授予成功。视觉壳只呈现当前表面厚度，不承担碰撞、质量或支撑。

材料厚度、contact/rest offsets 和可见壳厚度分别声明；前者进入材料先验，接触偏移决定接触包络。尺寸、面密度、质量、弯曲/拉伸参数和折叠参考均未经实物标定。代码和配置留在项目目录，可复用模型与纹理保存在共享 `assets`，数据与实验记录保存在共享 `datasets`，保留各自版本和来源。

## 机器人动作与观测

五项任务沿用一套 task-owned 对置双臂安装及五路 RGB-D。`active_sides=left/right`，同一条 `hand_geometries` 动作可含两手目标，不引入玩家或轮次。允许按压、夹取、搬运、重新接触和释放；不要求固定双手编排，也不把闭合手指或局部位移单独当作抓稳证据。

命名布料使用 `author-only` 初始化，保留原生预热状态。普通机器人回合只接受关节目标，不提供布点写入、隐藏固定点或工程抓持附件。冻结观察器在每个原生子步读取真实节点、速度、实际 cooked 机器人碰撞形状与分离状态。操作信用必须在同一连续近手段中形成：手相对该段起点净移动至少 1 cm，同时任务衣物至少移动 2.5 cm。

公开 Agent 使用 RGB-D、本体状态和静态规则。完整节点、材料层次、控制掩码、自交和穿透检查属于私有裁判；当前没有可用于声明夹持力或恒张力控制的布料接触力/张力读数。运动、几何接近、真实支撑和测得接触力是不同证据范围。

## 宽松但保持形态的成功条件

前三项保留 `laundry_practical_task.v2`，新准备的两项使用 `laundry_single_garment_folding_task.v3`，已冻结v2不自动升级。毛巾摊平/对折对应 RMS ≤ 3 cm，折后中心偏差 ≤ 5 cm。新衣物允许整件旋转，刚体XY对齐后的三维材料形状 RMS ≤ 3 cm、节点误差 P95 ≤ 6 cm、中心误差 ≤ 15 cm；更宽的合理台面放置范围不放宽折形本身。

服装还须保持参考轮廓、投影面积及至少85%的折层对应和台面支撑。v3允许参考折弧空气层压实至原有物理厚度下限，同时保留参考层距加12 mm的上限；不能要求自然压实后仍保留人为折弧空气隙。天然前后衣片独立检查有向Z间距，至少85%的加权材料对不得压到名义厚度45%以下，XY错位不能替代层厚。裤腿允许任一侧翻到另一侧，每种等价参考整体独立验收，不混用材料对应。展开、拉伸、团皱、悬空或明显穿插均不能成功。

新衣物v2/v3仅对完整原生审计确认的小范围穿插留容差：最长交线12 mm、交线总长75 mm、连通缺陷直径20 mm、唯一受影响材料面积0.2%、共面重叠面积1 mm²，五项须同时成立。保留原始pair数与严格零交叉诊断；不豁免相邻材料面，不接受截断清单。较大异常阻断成功并允许恢复，严重异常停止；毛巾与历史发布不采用新阈值。完整数值见 [RULES.md](RULES.md)。

所有目标都须在全部机器人碰撞形状离开全部任务衣物后，连续保持 0.5 s。每件每帧原始/位置差分速度 P95 ≤ 0.08 m/s，所有节点在滚动窗口内漂移 ≤ 15 mm。稳定窗口允许 2 mm 接触包络压入和 1.5 倍局部边长，允许中途小异常恢复后重试；reset 不得分，重新接触或目标失效会撤销当前成功。实际几何支撑不代表已测得接触力。

## 验证与历史记录

验证分别回答四个问题：资产与规则是否自洽；原生初始化和释放后的物理几何是否有效；Bench/Agent 是否使用相同发布并完成真实接口交互；机器人是否真的完成手布操作。每一项都需要绑定自己的源码、资产、发布与记录，不能相互代替。当前五项的具体冻结发布与证据见 [README](README.md) 及其后续来源绑定记录。

CPU 规则 fixtures 覆盖合理旋转、偏移、皱纹、抖动、释放恢复和失败反例，也区分严重层间压扁与允许的自然压实。它们是合成状态下的规则验证。原生初始化、微动、IK 或媒体检查通过同样不能推导完整抓取、对折或叠放成功；材料标定和策略泛化需要额外证据。

2026-10-21 最初提出三项毛巾任务，随后按用户授权先进行显式局部工程抓点验证；当时 Task1 使用工程入口，Task2/3 后续加入双臂安装。这些历史输入、脚本命令、失败对照、严格诊断和实用验收都在 [README 的历史章节](README.md)保留。工程抓点最多两个局部抓区，解除全部控制后再检查稳定；这些工程成绩不迁移为机器人抓取成功。

历史单片布料特权拖移见[工程基线](../../../docs/agent_bench/engineering_baselines.md)及独立终审（开发存储 `datasets/fr3_sharpa_bench/development/privileged_agent_baseline_20261013T173607Z/adversarial_audit/cloth_full_03_evidence_audit.json`）。该记录采用固定初态和零模型调用，不是视觉策略泛化结果。本次五项范围也不启动历史 cloth 训练队列。

实现入口：[任务组合](composition.py)、[单件折叠资产](garment_folding_assets.py)、[公开规则](rules.py)、[私有裁判](evaluation.py)、[原生观察器](native_observer.py)。共享后端继续负责原生布料、机器人控制、媒体和逐步审计；场景定义负责具体物体、初态和任务合同。

## 参考工作及采用边界

- [SoftGym，论文 §4、附录 A](https://proceedings.mlr.press/v155/lin21a/lin21a.pdf)：可借鉴摊平覆盖率、对折对应位置指标；其 picker 抓取采用粒子绑定的简化，不能直接作为 SHARPA 接触抓持证明。
- [FabricFlowNet，论文 §3.6、§4](https://proceedings.mlr.press/v164/weng22a/weng22a.pdf)：将单次与多次折叠分开，并分别评价仿真节点误差与实物图像；它假设折前已摊平，仿真仍使用绑定粒子的 picker。
- [Cloth Funnels](https://arxiv.org/abs/2210.09347)：把衣物展开形态和整体位置/朝向共同规范化，适合支持“先摊平摆正，再折叠”的拆分；其甩布动作不是当前项目已实现能力。
- [NVIDIA Omni Physics deformables 文档](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/latest/dev_guide/deformables/deformable_bodies.html)：说明三角表面变形体、独立渲染网格及材料限制；静摩擦不生效，多材料与部分表面参数也有限制。具体适用性仍以本机固定版本和有效原生属性为准，不自动升级共享运行时。
