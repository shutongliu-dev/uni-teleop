# 洗衣五项任务规则

本页说明五项洗衣任务，均可在创建回合前选择单臂、同侧双臂或对置双臂。实际判定以所选冻结发布内的 `rules.json`、`rules.py` 和 `sequence_evaluator.py` 为准。Task1/2使用 `laundry_practical_task.v2`，Task3的当前发布显式使用 `laundry_practical_stacking_task.v3`，单件衣物折叠使用 `laundry_single_garment_folding_task.v4`；已冻结的 v1/v2/v3 发布保留原规则，不会自动迁移。衣物v3允许参考空气隙自然压实；衣物v4仅将折层上方空气/褶皱余量从12 mm改为25 mm，其他衣物v3判据不变。

| 编号 | canonical ID | 整理目标 |
|---|---|---|
| Task1 | `towel_flattening` | 将局部折回的毛巾展开、摊平、摆正并释放 |
| Task2 | `towel_folding` | 沿长边中线对折，保持两半基本重合并释放 |
| Task3 | `towel_stacking` | 将已折毛巾移到另一条动态已折毛巾上 |
| Task4 | `shirt_folding` | 将单件展开T恤收袖、折好后放置释放 |
| Task5 | `trousers_folding` | 将单条展开长裤对齐裤腿、折好后放置释放 |

## 动作、操作信用与释放

一个 Agent 通过普通 `/episodes` 操作所选安装：`single_arm` 为一台 FR3 与官方右 SHARPA，共 29 DOF；`dual_same_side` 和 `dual_opposed` 均为两台 FR3 与官方左、右 SHARPA，共 58 DOF。单臂允许依次重抓和借助台面整理，不要求双手操作。只允许机器人关节动作，不允许直接写布料节点、隐藏固定点或工程附件。允许重抓、纠偏和恢复，不强制唯一轨迹或双手动作顺序。

初态只建立基准。操作信用要求至少一只手在同一连续原生碰撞几何近布段内，相对该段起点净移动至少 1 cm，且被搬/整理衣物的节点位移至少 2.5 cm；静止接近、空中挥手和先前被动下落都不能制造信用。几何接近取自实际 cooked 手部碰撞形状，不能用腕点距离代替。

全部机器人碰撞形状必须与全部任务衣物分离后，才能计释放稳定时间；手指张开但手掌或机械臂仍托住布料不算释放。目标形状、支撑、有效物理证据与以下条件须连续保持 0.5 s：

- Task1/2与单件衣物：每件、每帧的原始节点速度 P95 和相邻原生步位置差分速度 P95 都不超过 0.08 m/s；最近 0.5 s 内，每个节点相对该窗口起点的三维漂移不超过 15 mm。
- Task3 v3：每条毛巾在每个原生步，按与20 ms前真实位置的差计算节点速度，P95不超过0.08 m/s；全部节点在0.5 s窗口内相对窗口起点的三维漂移不超过8 mm。须有连续原生帧及额外20 ms前史；原始速度和相邻原生步位置速度完整保留诊断。
- 所有控制已解除，重力开启，无隐藏约束；前三项要求最终无实际布面自交或布间交叉，新单件衣物按下述尺寸阈值判断微小局部穿插。

重触、滑走、形态失效或接触异常会撤销当前成功并重新计时。缺失、不连续或无法核对的原生证据记为 unknown，不得分。

## 毛巾几何容差

当前 `contact_v2` 毛巾为 60 × 40 cm、名义材料厚度 4 mm、每条质量 0.144 kg 的动态表面；这些数值是仿真先验。Task1 初态含 12 cm 局部折回，真实无控制沉降后仍保留折回，不能被动等待得分。旧 3 mm / 0.108 kg 发布保留自身原参数。摊平与对折允许 180° 等价朝向，对折允许任一材料半边翻到上层。

| 检查 | 实用阈值 |
|---|---|
| 摊平位置 | 面积加权对应 RMS ≤ 3 cm，最差节点误差 ≤ 7 cm |
| 摊平形态 | 三角形 XY 投影面积之和 ≥ 静止面积的 90%；高度范围 ≤ 2.5 cm；保持台面支撑 |
| 对折对应 | 两半面积加权 XY 对应 RMS ≤ 3 cm；Task2 v3的材料面积加权P95 ≤ 6 cm、全点绝对误差 ≤ 8 cm；旧v2与Task3内部折形保留全点6 cm上限 |
| 对折轮廓与位置 | 折后约 30 × 40 cm，各轴尺寸偏差 ≤ 5 cm，高度范围 ≤ 4 cm；中心偏差 ≤ 5 cm |
| 对折层次 | 至少 85% 的加权材料对应保持统一上下顺序，层间中面间距 1–25 mm |
| 毛巾叠放 | 两条都通过折形与位置判断；v3高度采用静止三角面积均分到顶点后的加权P99减全节点最低点≤40 mm，且全节点绝对高度差≤45 mm；下条由台面支撑；上条至少 85% 的底层采样由下条实际布面支持，对应 XY 偏差 ≤ 5 cm、中面间距 1–20 mm |

摊平同时检查整片位置、方向、面积和高度；对折与叠放同时检查材料对应和层次。仅俯视轮廓相似不能得分。

Task2新增可显式选择的`laundry_practical_folding_task.v3`，公开规则版本为`laundry_rules.v6`，默认构建与现有冻结v2发布不变。它保留对应RMS≤3 cm，把原全点6 cm上限改为材料面积加权P95≤6 cm，并保留全点8 cm绝对上限；每对的权重为两端顶点各自分得的静止三角面积之和。这样允许少量自由边角卷起，不因一个角否决整体对齐的毛巾。原轮廓、高度、层序、支撑、物理守卫、操作信用与完整0.5 s释放稳定要求全部保留；不能以百分位掩盖漏折、大范围错位、严重变形或仍被手托住的结果。旧v2结果不得被新规则复评覆盖，接口资格也必须绑定各自冻结发布。

当前Task2三种安装的发布显式选择该v3规则，冻结来源为`source_configuration_runtime07`；机器人、初态、材料和物理配置与原`contact_v2`四文件逐字节相同。原辅助动作`captured_towel_fold_native09`在旧v2中只有局部自由角超过6 cm，其原失败保留；新规则对同流末1001帧的形状、释放和稳定复评通过。该复评没有重新执行动作，也没有整流普通SequenceEvaluator操作评分，不能当成普通Agent或纯摩擦整任务成功。三项普通Bench/Agent接口验证独立记录。

Task3 v3只容许占静止材料面积不超过1%的轻微边缘卷起，不能以P99隐藏整体蓬起；45 mm绝对高度和8 mm全节点漂移仍限制离群点及大幅往复。原v2默认构建路径和历史冻结发布均不变，不追溯覆盖结果。`captured_towel_stack_native08`的原v2末窗失败保留；同原始流在v3下仅终态形状、释放与稳定条件离线通过。该视频采用真实双指捕获后的局部手腕辅助，没有整段普通机器人任务裁判评分，不能称为普通Agent整任务成功。原失败轨迹04在新规则下仍因漂移和高度失败。

## 单件T恤与长裤折叠

Task4/5 每项只有一个动态衣物，从展开状态开始。T恤目标是收拢袖部并将下摆向领口方向折好；长裤目标是对齐裤腿后将裤脚向腰部折好。不固定抓点、动作顺序或整体朝向，但不能只把展开衣物搬到目标区、压成小团或预先用已折初态得分。

内部衣物ID沿用 `towel`，不存在 `towel_base`。原始衣物初态与静止材料网格等距；也允许使用带真实PhysX状态流与哈希来源的已沉降展开初态，保留原有材料网格及有限原生形变，不能预折得分。目标折叠参考、材料对应、层次与底面采样均随资产冻结。参考只供裁判检查，不能作为逐点运动目标写回布料。穿着态衣物的临时XY投影不等于真实展开参考；标记为未资格的投影参考不能授予成功。当前 `contact_v2` T恤名义厚度为 1.6 mm、质量 0.240 kg；长裤为 1.8 mm、0.390 kg。资产支持 0.5–2 mm 的参数范围，实际数值以所选冻结资产及其公开材料合同为准；历史 1.2 mm 发布保持原身份。

每件衣物都须通过以下形态判据；无需每个角完美重合，允许整件在台面内旋转：

| 检查 | 实用阈值 |
|---|---|
| 材料形状 | 只做台面内刚体旋转/平移及整体高度对齐后，三维材料点面积加权 RMS ≤ 3 cm，节点误差 P95 ≤ 6 cm |
| 尺寸与高度 | 对齐后 XY 各轴范围与参考相差 ≤ 5 cm；高度范围不超过参考高度范围加 4 cm |
| 投影面积 | 所有三角形 XY 投影面积之和为折叠参考的 80%–120% |
| 放置中心 | 参考包围盒中心经刚体变换后的目标偏差 ≤ 15 cm |
| 材料层次 | 至少 85% 的加权参考材料对保持上下顺序；XY 相对位置误差 ≤ 3 cm；v4层距 ≤ 参考层距加25 mm，且层距 ≥ max(0.5 mm, 资产材料厚度的一半)，允许参考空气隙自然压实 |
| 天然双面间距 | 独立检查衣物天然前后衣片；至少85%的加权对应点有向Z间距 ≥ 资产材料厚度的45%，平面错位不能代替厚度 |
| 单件台面支撑 | 至少 85% 的冻结底部采样，在台面上方半材料厚度的基准位置附近，允许向下 2 mm、向上 12 mm |

单件折叠的功能目标允许厘米级褶皱和未压平的折层空气。v4在保留完整材料对应、30 mm平面配对、40 mm额外高度和天然双面厚度的前提下，允许参考层距加25 mm的上限；这不放宽半折、零厚、反序、拉伸或严重鼓团。v3保留参考层距加12 mm上限，v1/v2保留相对参考层距双侧误差不超过12 mm的原判据，均不追溯改写。

同一条真实T恤轨迹 `fold_flat_shirt02` 在25 mm候选规则下的末0.5秒形状/释放/稳定检查通过，末帧折层比例约85.65%，本次裕量较小，不代表多次运行鲁棒率。其原v2报告及v3重评仍失败；错误外翼长裤 `fold_trousers08`、展开初态、压扁层、高鼓包和大交线反例仍失败。这个离线规则比较没有重新运行物理，也不代表普通机器人策略资格。

长裤允许任一裤腿翻到另一裤腿上。等价折形各有冻结的材料点参考、折层对应、天然双面对应与底面采样；满足任一完整参考即可，不交换材料点身份或混合不同参考的局部条件。

材料厚度下限允许初始折层的空气间隙在释放后自然压实，同时阻止多层几乎压成单层。旧 `laundry_folded_garment_task.v1` 仍保留层距至少为参考的 25% 且不小于 0.5 mm 的原判据，旧发布不会自动采用 v2。形状、局部材料层次、面积、实际支撑和全帧交叉审计共同判断展开、塌陷与严重失真。新单件折叠只检查本件衣物与原有台面的几何支撑，不使用第二件衣物。历史两件叠放中的布面支撑规则保留在各自旧发布内，不迁移为新折叠任务成绩。

## 接触异常与恢复

稳定窗口允许厚度包络压入不超过 2 mm，局部边长不超过静止值的 1.5 倍，三角形面积不低于静止值的 1%。超出这些范围的局部形变或接触异常会阻断成功；恢复后可以重试。毛巾及历史服装profile仍要求成功窗口内零实际交叉。

新单件折叠 v2/v3/v4 允许有限微小穿插，但须同时满足：单对交线长度 ≤ 12 mm、逐对交线总长 ≤ 75 mm、每个连通缺陷的空间直径 ≤ 20 mm、涉及的唯一三角形静止材料面积占全衣 ≤ 0.2%、共面重叠面积之和 ≤ 1 mm²。相邻材料面不豁免，交线总长保守相加，原始对数与严格零交叉诊断独立保留；完整pair清单缺失或截断不能得分。这些是针对当前衣物网格验证的工程容差，未声称跨网格标定。形状、厚度、层序与支撑要求全部保留。

明显异常会停止任务：压入超过 1 cm、任一局部边长超过 2 倍或原生物理失败。毛巾及历史profile仍按同帧交叉对数合计超过8停止；新单件v2/v3/v4改为任一交线超过50 mm、交线总长超过500 mm、连通缺陷直径超过100 mm、涉及材料面积超过2%、共面重叠面积超过50 mm²或出现第二件布料交叉时停止。超过成功阈值但未达停止阈值可恢复重试。每帧都须有完整重力、控制、碰撞和拓扑证据。任务预算为 120 s；预算耗尽不计完成。

严格几何与最大速度诊断独立保留。CPU 合成正反例只验证规则；原生初始化和 Bench/Agent 接口微动、完整机器人手布操作、标定材料物理分别需要自己的来源绑定记录。历史工程抓点成绩继续属于原控制模式，不能转为机器人抓取资格。
