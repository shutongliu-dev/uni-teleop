# Task1：遥控器开启电视倒计时并归架

按用户 2026-10-26 的要求，本次同时修改初态与任务语义：**拿起按钮朝上的遥控器 → 完整按下并松开红色电源键 → 电视显示 10 秒倒计时并自动关机 → 将遥控器放回收纳架、松手稳定 300 毫秒**。不再要求先翻正，也不再要求第二次按键关机。确认键 `confirm` 不影响电视和任务进度。

旧初态把遥控器正面朝下，按钮在桌面图中被壳体遮住；两个实体按钮并未缺失。新初态让按钮朝上，保留原独立刚体、壳体开孔、2 mm 弹簧回位行程和真实接触触发。单臂保持同手悬空握持；单 Agent 双臂变体允许官方左右手协作，仍需真实手指接触与按键释放回弹。长按不重复触发，桌面支撑中的按键不计。

电视初始关闭。有效电源键释放启动连续原生仿真时间的 10 秒倒计时，屏幕显示 10、09……01，结束后黑屏。自动关机保留本次完成周期资格，随后归架即可；关机本身不等于成功。提前按电源键关机可重试，再次开启从 10 秒重新计算。归架稳定窗口只在合格自动关机后累计，重新开机后需重做完整周期；已经判定成功的回合保持终态。

归架仍要求完整壳体处于收纳架容许范围与朝向内、有真实支撑接触、两键释放、无机器人接触，并连续稳定 300 毫秒。允许重抓、调整和桌面辅助；出界、掉地以及缺失原生证据沿用原规则。数码面片只改变电视显示，不产生碰撞、操作动作或成功状态。
