# Task1：遥控器控制电视并归架

任务顺序为：**用实体遥控器打开电视 → 连续保持开机至少 10 秒 → 用遥控器关闭电视 → 将遥控器放回收纳架并松手稳定 300 毫秒**。单臂 FR3／右 SHARPA 操作原有背面朝上的遥控器，需要先翻正；电源键按压必须在同手真实握持中完成。确认键 `confirm` 不参与目标。

电视初始关闭。完整的电源键触发、真实松开回弹周期切换一次电视状态；长按不重复触发。10 秒按连续的原生仿真时间计量，提前关机后重新开机从零计时。达到 10 秒不会自动关机或成功，必须再次有效按电源键关机，然后归架；初态关机、只完成关机或手持于架上均不能成功。

归架稳定时间只在完成合格关机后累计；再次开机会清除归架资格。归架要求完整遥控器壳体处于收纳架容许范围和朝向内、有原生支撑接触、两键释放、无机器人接触，并满足逐子步运动与速度阈值的 300 毫秒稳定窗口。可在桌面辅助翻正、放下重抓，普通落回桌面可恢复；出界或掉到地面为失败，预算耗尽为未完成，缺失或不连续原生证据不评分。

电源和确认按钮是独立刚体，通过被动弹簧回位关节连接主体；真实手指接触、触发行程及释放回弹构成有效按键事件。电视画面由观察器的开关状态驱动，仅绑定屏幕视觉材质。普通 `/episodes` 和现有公开机器人函数负责操作，不提供直接开关电视或上传成功状态的动作。
