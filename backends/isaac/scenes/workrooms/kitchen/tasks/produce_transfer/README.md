# Task2 · 果蔬分类装盘

六个独立刚体：三个带蒂叶和分瓣外形的番茄、三根带根纹和自然稳定支撑面的短胡萝卜。固定夹具为源砧板和两个有真实底板、盘沿的分类浅盘。

六件果蔬分别进入番茄盘和胡萝卜盘，整个物体落在盘内、实际受盘底承托，全部松手稳定 0.4 秒。

无朝向或精确排列要求，可互相接触；错盘、台面滚动和重抓均可恢复。骑沿、悬空或只由其他果蔬托住不能算直接落盘。食材是刚体，不模拟切割或软组织。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.produce_transfer.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task produce_transfer`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。
