# Task6 · 餐后台面整理


新版 `household_grip_v1` 仅加厚餐具握柄：原 6.9 mm 厚度增至 13.8 mm，握持段长 87.4 mm，顶边倒角。加厚部分与原餐具同属一个动态刚体，视觉和凸碰撞一致；叉齿、刀刃、勺碗、原底面、摆放位置和收纳槽保持原样。按原有效密度随新增实体体积更新质量、质心和惯量，属于工程估计。规则数值、父房间及原有单臂机器人安装不变。下述旧版实验只说明各自旧输入，不转授新版抓握或动力学资格。

八件餐后器具：大小两只餐盘、两只不同形状的开口碗、两只带把手的杯、一把勺和一把叉。源台面与三个收纳区分别用于盘碗、杯具和餐具。器具为空，不伪造洗涤、液体或食物残渣效果。

把盘碗、杯具、勺叉放入对应收纳区，整个物体留在区内并有真实承托链，全部松手稳定 0.4 秒。盘碗可以自然堆叠，杯具保持直立，餐具柄向自由。

允许重新排列、解叠和重抓；不要求按固定顺序收拾或堆成指定形状。盘碗的同类堆叠须由真实接触最终连到收纳底面，不能悬空、骑边、越界或靠机器人维持。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.table_clearing.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task table_clearing`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。

历史版本 `household_contacthybrid_v1`，采用与餐具任务相同的勺和叉碰撞修复：原开口勺碗为独立 SDF，原柄部为 4 个经过局部坐标条件化的凸块，叉的原实体为 14 个凸块。实际形状、碗腔、原视觉、质量、质心、完整惯量、材质、阻尼和共享控制器不变；支撑平面仅细分原接触网格，原边界和体积保留。

冻结 `source14` 的源位置和目标位置各保存 3201 帧、3200 个原生步，步长仍为 0.0005 秒。八件物品末 0.4 秒的全部原始速度样本均满足原 0.025 m/s、0.25 rad/s 门限。勺在源位置和目标位置的角速度峰值分别为 0.134678、0.025274 rad/s，不再依赖旧候选接近 0.25 rad/s 的临界通过。完整 800 区间的逐体有符号法向承重包含物体间接触的正负抵消，另保留同一原生步的三套未修正接触 API；这些证据不等于完整摩擦或力矩标定。

冻结 `source15` 的普通 HTTP 与实际 Agent 客户端通过四路 RGB-D、只读 IK、实际腕部移动、返回、保持和幂等重放，模型调用为零。最终几何原生查询保持独立源码绑定。当前形状的离散工作空间为 32/32 IK、31/32 固定待机手型的 5 mm 净空；叉的目标近接点仍未通过净空，不能声明所有抓取或连续路径合格。

`source17` 原生几何读回确认每勺 5 个碰撞形状、4 个柄部凸块的实际顶点与原形状一致。原探针在约 5 mm 远场的 SDF 全域距离门槛仍失败；原始报告和 exit 1 保留。同一原始场数据的离线材料/空腔符号、梯度和采样零面夹逼检查通过，接触边界样点最大误差 2.325 µm，满足原几何距离上限；不声称整个远场都具有该距离精度。

完整版本、原始数据、独审及历史失败见本轮验证索引（开发存储 `datasets/fr3_sharpa_bench/development/kitchen_flexible_velocity_fix_20261024/velocity/qualification.json`）。旧 SDF 临界通过、220 凸块的 cooking 裁形、异常法向读数和目标角速度失败均保留，不通过比例修正接触数据。准备态 `physics_accepted` 与完整机器人任务资格仍为 false。
