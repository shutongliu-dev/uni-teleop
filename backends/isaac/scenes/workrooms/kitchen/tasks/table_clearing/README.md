# Task6 · 餐后台面整理

八件餐后器具：大小两只餐盘、两只不同形状的开口碗、两只带把手的杯、一把勺和一把叉。源台面与三个收纳区分别用于盘碗、杯具和餐具。器具为空，不伪造洗涤、液体或食物残渣效果。

把盘碗、杯具、勺叉放入对应收纳区，整个物体留在区内并有真实承托链，全部松手稳定 0.4 秒。盘碗可以自然堆叠，杯具保持直立，餐具柄向自由。

允许重新排列、解叠和重抓；不要求按固定顺序收拾或堆成指定形状。盘碗的同类堆叠须由真实接触最终连到收纳底面，不能悬空、骑边、越界或靠机器人维持。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.table_clearing.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task table_clearing`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。
