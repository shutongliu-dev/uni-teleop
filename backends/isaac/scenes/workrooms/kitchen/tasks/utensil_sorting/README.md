# Task3 · 餐具分类收纳


新版 `household_grip_v1` 仅加厚餐具握柄：原 6.9 mm 厚度增至 13.8 mm，握持段长 87.4 mm，顶边倒角。加厚部分与原餐具同属一个动态刚体，视觉和凸碰撞一致；叉齿、刀刃、勺碗、原底面、摆放位置和收纳槽保持原样。按原有效密度随新增实体体积更新质量、质心和惯量，属于工程估计。规则数值、父房间及原有单臂机器人安装不变。下述旧版实验只说明各自旧输入，不转授新版抓握或动力学资格。

六件有厚度的餐具：两把有凹面的勺、两把带独立叉齿的叉、两把钝餐刀。源垫和三格收纳盘是固定夹具，格间有真实碰撞隔板。

勺、叉、钝餐刀进入各自收纳格，物体完整容纳并有真实支撑链，六件全部松手稳定 0.4 秒。

柄朝两端均可，同类餐具允许并排或轻微搭叠；不用精确角度。错格、跨格或拥挤可以调整，不立即判输。跨隔板或其他类别物品托住不能冒充正确收纳。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.utensil_sorting.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task utensil_sorting`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。

历史版本 `household_contacthybrid_v1`：叉和刀的原实体分成 14 和 5 个凸块；每把勺保留原开口碗部的独立 SDF，并把柄部分成 4 个凸块。柄部只采用局部坐标缩放和反向子节点缩放，保持实际形状，同时避免小凸块在原生 cooking 中被裁掉。原视觉、质量、质心、完整惯量、材质、阻尼和共享控制器不变；源垫和收纳格只细分原平面接触网格，边界与体积不变。

冻结 `source14` 的源位置和目标位置各保存 3201 帧、3200 个原生步，步长仍为 0.0005 秒。六件物品末 0.4 秒的每个原始速度样本均满足原 0.025 m/s、0.25 rad/s 门限；两把勺在源位置的角速度峰值为 0.012153、0.004088 rad/s，在目标位置为 0.046535、0.009600 rad/s。完整 800 区间的逐体法向承重诊断及同一原生步的三套未修正接触 API 另行保存，不将法向重量一致写成完整摩擦或力矩标定。

冻结 `source15` 的普通 HTTP 与实际 Agent 客户端验证通过四路 RGB-D、只读 IK、实际腕部移动、返回、保持和幂等重放；模型调用为零。最终几何来源与原生查询单独绑定，不将后续源码整体视作已通过物理运行。当前形状的离散工作空间为 24/24 IK、24/24 固定待机手型的 5 mm 净空；这不代表抓取或连续路径通过。

`source17` 原生几何读回确认每勺 5 个碰撞形状、4 个柄部凸块的实际顶点与原形状一致。原探针在约 5 mm 远场的 SDF 全域距离门槛仍失败；原始报告和 exit 1 保留。对同一原始场数据的离线独审检查材料/空腔符号、梯度及采样零面夹逼，接触边界样点最大误差 2.243 µm，满足原几何距离上限。该边界结论不扩张成整个远场的距离精度承诺。

完整版本、原始数据、独审及历史失败见本轮验证索引（开发存储 `datasets/fr3_sharpa_bench/development/kitchen_flexible_velocity_fix_20261024/velocity/qualification.json`）。保留仅改支撑网格、整勺 SDF768、220 凸块及探针接线失败的原始记录；不可用某一子检查通过代替整个候选合格。准备态 `physics_accepted` 与完整机器人任务资格仍为 false。
