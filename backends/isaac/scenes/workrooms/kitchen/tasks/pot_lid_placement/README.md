# Task4 · 冷灶锅具就位与锅盖盖合

两个独立动态物体：带空腔、卷边及双耳的空锅，带盖沿和防滑钮的独立锅盖。固定源垫在备菜台，指定前左炉位始终为冷灶。

先把锅放在指定炉位中心 35 mm 范围内，实际承托并松手稳定 0.3 秒，锅盖仍分离；再盖好盖子。锅盖允许 12 mm 偏心、8°相对倾角和 8 mm 高度误差，锅与盖共同松手稳定 0.4 秒。

不规定锅耳或盖钮的旋转方向。放歪可以重抓、重放；锅和盖预先拼好再一起搬运不满足先放锅的顺序。任务不涉及加热、沸腾或密封测试。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.pot_lid_placement.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task pot_lid_placement`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。
