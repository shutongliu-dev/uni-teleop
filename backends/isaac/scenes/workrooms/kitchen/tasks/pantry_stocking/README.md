# Task5 · 食品与调料归位

八种独立密封物品：橄榄油瓶、醋瓶、盐罐、胡椒罐、红椒粉罐、米盒、意面盒和番茄罐头。瓶肩、瓶颈、盖纹、纸盒折边、金属罐卷边及标签区别材质和类别；内容物不参与液体或颗粒模拟。

把油和醋放入瓶装区，盐、胡椒和红椒粉放入调味区，米、意面和罐头放入干货区。物品完整容纳、油醋瓶与调味罐基本直立（纸盒和罐头可平放）、由目标容器或同类物品真实承托，全部松手稳定 0.4 秒。

同类物品不指定格位或标签朝向，不要求排成直线。错区或倾倒可以扶正、取回重放；几何接近但无承托、手未松开都不算完成。

本任务另有 12 件任务所属的固定背景物品，公开目标中明确列为非评分陈设；它们不计入上述可动物品，也不能替代任务物品。父厨房保持原版本，背景物品不会被当作可抓取动态对象。

配置入口为 `scenes.workrooms.kitchen.tasks.pantry_stocking.task.task_configuration()`；bench 使用该任务冻结 release 的普通 `/episodes`，Agent 使用 `--family kitchen --task pantry_stocking`。编号别名、发布版本及验证记录见[厨房总说明](../../README.md)，裁判合同见[规则](../../RULES.md)。

裁判读取连续原生位姿与接触，初态没有完成信用；预算耗尽为未完成，缺失证据为无有效判定。质量与材质为公开仿真先验。场景承托及接口检查与机器人完整操作成绩分别记录。
