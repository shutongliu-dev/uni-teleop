# Task9 · NIST ATB4 多线束装配与取下

红线两端分别装入两个红色端子，蓝线两端分别装入两个蓝色端子。每根同色导线的两端外观相同，允许整根掉头装配，两端可以互换；两个端头必须分别占用两个不同的同色端子。两根导线都要经过共同导向区域，松手稳定确认后，再把全部导线与端头取下放入收集托盘。

新增重点是多线配对、成束整理和分阶段整体取下；不重复单根线缆任务，也不要求扎带锁紧。 这是根据 NIST 原始资料改编的去重任务，不声称完整复现官方板件或评测协议。原机械 Task1–5 保持独立。

- 场景入口：`task.py`；公开规则：`rules.py`；裁判入口：`evaluator.py`；发布指针：`definition.py`。
- 复用固定机械室、原 FR3＋右 SHARPA 和原支架；物件、工装、初始化与裁判属于本任务。
- 素材存放共享 assets，冻结 release 和实验存放共享 datasets，不在任务源码目录堆放模型。
- 接口：普通 `/episodes`；Agent 选择 `--family mechanical_assembly --task task9`、`L9` 或 `nist_wire_harness`。
- 允许重抓、退出重插、错放纠正及重新布线。达到目标后需要真实支撑、脱离机器人接触并稳定 0.3 秒。
- 预算耗尽记未完成；证据缺失不制造成功或操作失败；初始化不计任务分。

柔性件使用被动关节连接的短段刚体近似，具有真实重力和碰撞；不宣称材料弯曲精度。连接器只评估几何插接与支撑，不宣称电气导通或卡扣锁紧。手物交互交由数采，本轮只承担场景和物物可行性。

当前使用 `usability_v2`：端头放大 1.6 倍、线径 4.5 mm、槽宽 9 mm，并加宽收集盘及开放底部支承条；保留 64 个动态体、62 个关节和原线长。实际成束配合与释放稳定通过原生物物检查，完整两线入盘另有静态几何见证。 三种构型可在开局选择；完整抓取、布线／拆除仍由数采验证。

各版本的实际原生证据和限制见 [NIST 任务说明](../../NIST_TASKS.md)。

## 同色端点等价修复

当前选用 `desktop_v2`（由新规则基础版 v4 派生，继续使用资产 v4）。新规则不要求 Agent 区分外观相同的隐藏 A/B 身份；每根线的正向或整根反向分别作为一个完整配对方案检查，反向方案同时翻转端头目标朝向 180° 和沿线检查方向。每个方案仍要求两个不同同色端子、对应端子的真实配合／支撑，以及两个共同导向区域；红蓝混配、两端同槽、缺少接触和直接入盘均不能完成。

这是公开规则与裁判的一致性修复，未添加文字标签，未改变零件、关节、接触材质、物理参数、稳定阈值或共享控制。装配后释放确认再拆除的阶段顺序保持。原 v3／desktop_v1 和其证据保留。见 修复及接入证据（开发存储 `datasets/fr3_sharpa_bench/development/mechanical_routing_public_20261021/qualification.json`）。
