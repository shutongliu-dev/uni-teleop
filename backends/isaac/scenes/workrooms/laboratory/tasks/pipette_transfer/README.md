# Task5：跨台定量移液分装

岛台供液杯初始装有 80 mL 水。使用独立活塞式移液工具吸水，再向后台两个接收杯分别分装 10±2 mL，工具归架并松手。累计洒漏不超过 2 mL，未决飞行水不超过 0.5 mL。公共规则和裁判由实验室公共任务模块提供；这里负责器具和液体模型。

器具使用真实动态筒体、独立动态活塞及 Z 轴 prismatic 约束。筒体内径 24 mm，行程 55 mm，最大排量约 24.88 mL。吸嘴真实开口内径 6 mm。供液杯和两个接收杯都有真实中空碰撞壳；归架依靠指托和支架支撑。所有资产由 `assets.py` 在统一实验室任务根路径下生成，原固定房间和机器人不变。

## 明确采用的液体近似

`liquid.py` 是独立的有限体积物理组件，不是判分脚本，也不声明使用 PBD 水粒子。它只接收逐原生子步的真实刚体位姿：

- 活塞实际向外移动时，只有吸嘴位于容器现有液面以下且未穿过杯底，才按活塞截面积乘真实行程转移水量。空吸增加空腔，不制造水。
- 活塞压入时，根据实际排量、工具内现有水量及真实喷嘴朝向放出体积包；体积包按重力运动，只有进入实际杯口才记入接收杯。
- 停止活塞后没有自主排水指令；已经离开吸嘴的水继续下落。偏离杯口、杯超容积和倾斜造成的溢出计入累计洒漏。
- 每一步保证 `初始量 = 源杯 + 工具 + 两杯 + 飞行水 + 累计洒漏`。液体组件不读取 10 mL 目标，不访问裁判、控制器或模拟器句柄，也不设置容器位姿。

此模型省略细尺度压力、气泡、黏性、表面张力和飞溅。杯中液体采用近竖直液面及最低杯沿容量近似；倾斜达到 60° 时保守倾空。**没有把水重或射流反作用施加给原生刚体**，因此不能据此声称水重耦合或精密移液器标定。USD 预先包含源杯、两个接收杯和工具腔体的无碰撞液面。任务通过通用 `CylinderVolumeBindings` 在渲染同步点根据组件水量更新液面高度、局部 Z 和可见性；物理子步不写 USD，显示不参与判分，也不生成假水流动画。
