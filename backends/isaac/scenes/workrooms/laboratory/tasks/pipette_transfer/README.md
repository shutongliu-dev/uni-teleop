# Task5：活塞定量移液分装

这是注射式移液器任务：**吸嘴浸水，拉活塞吸水；移到杯口，推活塞分装**。它不是按一下按钮自动吸液的移液枪，也不需要把整个供液杯举起来倒水。

1. 岛台供液杯初始有 80 mL 水。握住工具筒身，将下端吸嘴移到水面以下、杯底以上。
2. 向外拉活塞吸水。筒内水量随实际活塞行程增加；未浸水的空拉不增加水量。
3. 把吸嘴移到后台接收杯口上方，压活塞出水，两个杯各达到 10±2 mL。允许分次吸取、补充、重新抓取和台面支撑，不规定左右手分工。
4. 把工具放回支架，所有器具松手后稳定 0.3 秒。工具可以保留余水；总洒漏不超过 2 mL，飞行水不超过 0.5 mL。

单臂、同侧左右双臂、对侧左右双臂均由一个 Agent 控制。双臂可以一手扶筒、一手拉推活塞；这只是可选操作方式。物物台架验证不替代数采侧的手物操作。

## 器具与观察

筒身、活塞和三个杯是独立动态刚体，支架固定。筒身内径 24 mm，真实活塞行程 55 mm，最大排量约 24.88 mL，吸嘴开口内径 6 mm。活塞保留被动阻尼，没有主动驱动或自动回吸。顶部拉环有真实开孔和碰撞，筒身侧翼用于支撑与握持；支架只用于归放。

透明杯壁和筒身、容量刻度、源杯和接收杯液面、筒内水柱及真实排出体积包的轨迹均通过相机观察。大块干重标签已移除；标称空载质量仍在公开任务规则中。浅色台面观察区衬托透明液面和水迹，只是无碰撞的印刷外观，不是额外目标区或支撑物。动态水量及洒漏账本是私有物理/裁判信息，不作为 Agent 的精确液量接口。

## 液体与水重近似

新资产显式选择 `laboratory_piston_finite_volume.v2`；历史 v1 资产保持原行为。沿用客厅的守恒、可见水和载荷原则，但没有把其较大的 PBD 粒子塞进细吸嘴：本任务仍是明确声明的有限体积近似。

- 实际抽拉量为活塞面积乘真实相对行程。只有吸嘴实际位于已有液面下，才把容器中的水移入筒身；压入时最多排出现有水量。
- 排出的体积包根据喷嘴实际位置、朝向和运动速度离开，再按重力运动。只有进入实际杯口的水才入杯，没有吸向目标的力或目标驱动流量。
- 每步保持 `80 mL = 源杯 + 筒内 + 两个接收杯 + 飞行水 + 累计洒漏`。水差为初始量减去各容器及筒内水，扣除飞行水后得到洒漏；回收不抵扣累计洒漏。
- 液面和体积包在独立渲染同步中更新，不生成碰撞、不修改液路、不参与判分。湿痕只表示已有明确落点的水；倾杯等未求解落点的洒漏不伪造轨迹。
- 通用 `reduced_liquid_payload` 适配器按实际守恒液量，将水的质量、质心和惯量合并到相应原生刚体；飞行水及洒漏不再算入容器载荷。干重基线保持独立，避免重复计算。公开物品质量仍是干重。

这是随容器运动的等效水柱载荷，不模拟晃荡、细尺度压力、气泡、黏性、表面张力或射流反作用，也不声明精密仪器标定。倾杯使用最低杯沿容量近似，倾角达到 60° 时保守倾空。

液路组件不读取 10 mL 目标或访问裁判、控制器、模拟器句柄；载荷适配器独立读取原生状态并更新质量属性，不驱动物体位姿。数值目标和容差保持原任务值。
