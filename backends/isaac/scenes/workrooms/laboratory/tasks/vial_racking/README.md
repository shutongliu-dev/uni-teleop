# Task2：试管跨架转移

三支密封试管初始竖直插在岛台的源试管架中。将它们向上取出，转运到后台另一试管架，分别插入三个不同的空孔并松手放稳。孔位无需对应试管身份，允许重新抓取、对准和调整。

每支试管长 90 mm、质量 20 g。源架有真实底板、开孔导向环和支柱；试管保持独立动态刚体，没有固定关节或隐藏附着。源架底板为 260 × 110 × 6 mm，孔中心间距 80 mm，内径 24 mm。导向环位于底板坐标 Z=25–31 mm，初态每支试管约有 65 mm 露出导向环，便于从上部抓取后向上抽出。

目标架及原试管碰撞、质量、摩擦和裁判阈值保持原定义。完成仍要求三支管分别进入不同目标孔、基本竖直、获得目标架的真实支撑，并在释放后稳定 0.3 秒；源架初态不计完成。单臂、同侧双臂和对侧双臂都使用同一任务规则。

资产作者为本目录的 `assets.py`，共享规则在实验室家族的 `rules.py`。源架继续使用固定器具 ID `supply_cradle`，目标架为 `rack`；这两个 ID 只用于场景结构和接触读取。验证记录独立保存于共享 datasets，不参与任务加载、启动许可或逐回合裁判。

当前源架版本为共享资产 `laboratory/vial_racking/v4`，单臂发布为 `laboratory/vial_racking/v5`；同侧、对侧双臂对应 `robot_configurations_20261025/lab_vial_rack_transfer01` 下的独立发布。Bench 与 Agent 沿用 `--family laboratory --task task2`，可用 `--configuration auto` 在回合创建前选择三种构型，或直接指定构型。双臂由一个 Agent 操作官方左右手。
