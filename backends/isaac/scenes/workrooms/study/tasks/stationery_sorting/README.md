# Task1 · 文具分类（`stationery_sorting`）

书房任务按 Task1 文具分类 → Task2 按序叠书 → Task3 指定书取出 → Task4 按类别上架，由易到难递进。本任务侧重桌面身份分类与抓放；该顺序是设计难度，不代表已验证的成功率。

将粗铅笔、马克笔和橡皮分别放入桌上与各自身份、类别对应的独立区域。目标采用物体完整包围盒，物体中心进入区域仍可能不够。

沿用 v4 的近桌布局：分类框中心为 x=0.50 m；三件文具的初始中心为 x=0.27 m、y=-0.30/0/0.30 m，长轴沿 Y。槽框、标签和冻结目标保持一致。实际布局与验证范围见[书房记录](../../../../../docs/scenes/study_room.md)。

铅笔 v5 资产将六角笔杆对角直径从 11 mm 增至 15 mm（对边约 12.99 mm），总长仍为 180 mm；真实六角杆与木质笔尖保留两个凸包碰撞体，印字宽度、贴面高度、包围盒和初始离桌高度同步调整。质量按原 8.1 g 与横截面积比例 `(7.5/5.5)²` 估计为约 15.062 g，并按新尺寸重算原包围盒近似惯量；该质量是同长度、同名义有效密度的工程估计，未经实测标定。

仅铅笔自身的静／动摩擦系数改为 0.70／0.55；马克笔、橡皮和分类框仍为 0.50／0.40。铅笔的恢复系数 0.02、接触偏移 1 mm、静止偏移 0，以及默认摩擦组合方式保持不变。以上数值是仿真材质先验，实际接触还取决于接触另一侧的材质。其他任务、机器人、控制器和评分阈值不随这次物品调整变化；独立动力学与抓放验证不作为任务输入或启动门槛。

所有任务物体必须整体进入各自三维目标范围，完全离开所有机器人部位，并由指定桌面、层板或紧邻下层书的真实有符号向上接触冲量承托。摆放、支撑、释放、速度和漂移条件须同时连续保持至少 300 ms。每个原生步为 0.5 ms；位置、方向、接触和时间阈值随公开规则冻结。初始状态不计分，必须发生实际机器人动作。

目标范围在支撑面处的下沿复用公开规则已有的 1 mm 最大穿透容差；若目标下沿已经预留余量，不再叠加。XY 边界及所有上沿保持严格，真实支撑接触和最大穿透检查仍独立执行。

预算内允许重新抓取、扶正和纠错；掉到桌面可恢复，任一任务物体真实接触地板则本回合失败。缺失、跳步、无效原生证据会使裁判无效；预算耗尽或取消记录为未完成。此时回合已经结束，而物理裁判保持 ongoing；公开回合结果分别记录预算原因或 cancelled，不把未完成伪报成物理失败。只能控制真实机器人，禁止写物体位姿、自动吸附或直接对任务物体施加外力。

`rules.py` 和 `evaluator.py` 是本任务入口，共用书房根目录的冻结配置和序列裁判。原生运行器私有读取每个物理步的状态与接触；公开接口仅提供规则及粗粒度裁判原因。CPU 合成序列用于验证评分逻辑，不能证明机器人完成了任务。原生初始化、图像检查和完整抓放成功分别记录，不继承其他任务或旧发布的资格。
