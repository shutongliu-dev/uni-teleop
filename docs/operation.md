# 操作、映射与反馈

## FACTR + MANUS

FACTR 是主臂，DYNAMIXEL 是电机与串口协议。七轴按保存的顺序、方向和零点映射到
Franka 的七个关节；默认关节模式不经过末端 IK。不能只复制原始编码器数值而省略
偏置/方向。主臂整体平移不改变关节标定，底座朝向与观察相机也不等于关节零点。

启动后接收主臂和手套，点击 **开始 / 恢复跟随**。**暂停**停止仿真跟随；实体托举
启用时暂停也会关闭托举。**重置场景**复位场景和物体，不是重新标定主臂。
**记录参考姿态**用于明确的重新标定；先重置、暂停并摆到对应姿态，按钮会等待
点击之后的新鲜主臂帧再记录，不能拿任意姿态当统一零点。

手套数据中断保持手指；部分恢复状态仍需暂停后重新开始。主臂和手套独立采集，
界面分别显示数据状态。手套指示灯亮不等于 SDK 已收到数据；以递增帧号、数据年龄
和实际关节变化为准。

## 实体托举与力反馈

代码包含 FACTR 低电流反馈、关节阻尼/限位提示和重力补偿，但默认配置均不使能。
重力补偿抵消主臂自身重量；这不等于从臂接触力的完整双向复现，也不保证任意位置
无漂移悬停。当前仿真关节标定和实体重力模型标定允许分开保存。

显式启动参数：

```text
--leader-feedback
--leader-gravity-urdf /path/to/measured/leader.urdf
--leader-gravity-calibration /path/to/physical-calibration.json
```

该模式仍由界面显式使能，要求匹配设备的实测标定。原实现的电流上限和失联行为
保持原样。未将上一次现场调参结果作为通用出厂参数。

## PICO

手柄模式用 grip 作为手臂离合，松开后可换握持位置；PICO+MANUS 时手指来自 MANUS。
裸手模式用手腕位姿和手指追踪，保留短暂丢失后的重锚定与恢复机制。
该路线按末端位姿求 IK，与 FACTR 七轴直接映射不同。
主画面、腕部和后方相机保持各自功能；相机视角不会重新定义 FACTR 的关节符号。

## SONIC

PICO 身体骨架经 SONIC encoder/decoder 控制 G1；头部和手指使用对应映射。
视频回传、episode 录制、接触和触觉皮肤代码保留。SONIC 的手柄振动提示是触觉事件，
不能与 FACTR 电机重力托举混称为同一种力反馈。具体按键见原 SONIC README。

## 当前练习模式

默认使用 CPU 刚体、关闭任务评分。碰撞和 40 次物理接触采样保留，穿透仅报警。
长链条的接触归约优化已包含；没有削减线缆/皮带分段，也没有改变物理步长。
本仓库没有自动把 `--unrestricted-arm` 或临时标定开关加入公共配置；需要复现某次
练习参数时可在 `--` 后明确传入。所有参数的具体语义见后端文档与启动脚本。
